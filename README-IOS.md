**Mobi Army 245** — Phiên bản Army được phát triển và tùy chỉnh trên nền tảng Unity, hỗ trợ iOS.

## ✨ Tính năng

- 🎯 Kẻ góc.
- 💎 Auto đập ngọc.
- ⚡ Cộng chỉ số nhanh.
- 🚀 Tùy chỉnh tốc độ.
- 🍎 Trải nghiệm game trên các thiết bị iPhone và iPad tương thích.

## 📦 Nền tảng

- iOS: iPhone / iPad
- Định dạng phát hành: IPA
- Game Engine: Unity

## 📥 Cài đặt

1. Tải file IPA.
2. Sử dụng phương thức ký và cài đặt phù hợp với thiết bị iOS.
3. Khởi chạy game sau khi cài đặt thành công.
